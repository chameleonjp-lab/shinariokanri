## Blocking findings

1. **Medium — an editable world hides additional retained registry editions of the same source.** `src/ui/WorldVersions.tsx:27`–29 loads an editable choice through `loadEditor`; line 35 uses that `sourceWorld` directly for the snapshot picker. `App.tsx:65` gives editable summaries precedence over registry choices for the same project ID, so `loadWorldSource` is skipped whenever that editable project exists. Concrete valid scenario: local editable world W contains S1; a subsequently imported independent work A bundles a newer W image containing S1 and S2 under the S2 registry key; open independent work B and choose W. Import writes the bundled W image only to `worlds` (`store.ts:1664`–1668), preserving the editable W. The former `mergeWorldSources(allProjects, fullRegistry)` exposed S1 and S2. The new picker shows only S1. Even when B's dependency closure already includes S2, the picker uses `sourceWorld` rather than the merged `availableWorlds`. Hydrate and merge the selected source's editable current and all its retained registry editions, retaining immutable snapshot identity and current editable content. Cover editable W plus additional registry-only edition, not just a registry-only project.

2. **Medium — a late pin save can replace the newly selected project's world dependencies.** `src/App.tsx:239`–245 captures project A, awaits its pin save, then unconditionally calls `setWorldRegistry(await listEditorWorldSnapshots(result.project))`. The project-switch button remains usable during this operation (`App.tsx:373`). If the user opens project B while A's save or post-save world read is pending, `applyProject` correctly declines to replace B with A, but line 245 still publishes A's dependency closure over B's registry. B's borrowed entities and snapshot previews can then disappear or fail resolution until reopened. Previously this call published the complete registry, so it did not discard B's pins. Fence this post-save publication by the captured selection generation and active project/revision; add a delayed A-pin completion after B opens with different dependencies.

Both findings were sent to the controller for implementation. A later fixed commit requires explicit re-review; this report describes the frozen source only.
