同じ段落IDの別公開本文による原稿上書きを正期待で再現し、失敗を保持する。
コピーを正本段落表から分離し、旧markerの公開側だけの再保存も検査する。
全単体の実結果・実runtime・生成schema／build／文書・計画／Pythonを各捕捉入力と結合する。
