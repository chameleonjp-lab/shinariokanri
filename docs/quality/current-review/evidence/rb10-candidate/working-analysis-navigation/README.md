# 探索打切り結果の画面移動後の保持

独立した通常productionの小fixtureで、C9の探索取消後に資料へ移ると結果と保存導線が消える差を再現した。正本12tableと未保存JSONは保持されることを補足実行した。この新観測は封印済みC9部分証拠への上書きではなく、別の補足である。

C10は作者・作品別の既存ReaderDraftへ結果・進捗・実行状態を保持し、画面退出時に共有controllerで中止する。戻った画面も同じ実行状態を参照し、取消結果を未確認として開ける。作者purge後の遅延書込はepoch/controllerの一致条件で停止する。改訂した現稿の結果は再確認を明示し、誤った現稿対象へ開かない。別の選択版でも検査対象版を表示する。

Chromium/Firefox/WebKit各2ケースがdirty buildで成功。取消、固定版hash待ちで退出・即時再入、原12table不変、不正JSON再開、選択版差、現稿改訂後の再確認、旧固定版の維持を確認した。元100,000状態・10,000遷移・30秒は不変。全764/81単体は単独成功。初回テストimport元の型エラーも保持する。

小fixtureの成功を原Large/長い分岐・実端末・実権限・全116・最終clean版へ換算しない。結果は試読の作者別メモリ下書きに保持され、検査JSONの明示持出しができる。新しい完全保存項目や未知の合格化は追加していない。
