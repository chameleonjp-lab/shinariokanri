## 再実行

単体検査:

```sh
npx vitest run tests/timeResolver.test.ts tests/timeEditing.test.ts tests/timelineLayout.test.ts tests/world.test.ts src/domain/maintenance.test.ts src/storage/worldPins.test.ts
npx tsc --noEmit --pretty false
```

最後の局所単体実行は6ファイル51件合格。このうちRB03所有の4ファイルは38件。`timeResolver.test.ts`は正規に検証可能な5,001出来事の相対連鎖を、validateProject→ScenarioStore保存→DB再接続→完全保存ZIP→読戻しまで実行する。別の10,000連鎖テストは索引解決だけの検査である。8,800/88,000レコードfixtureは年表の全出来事集合と端点到達を検査する。実端末p95やブラウザー全件描画の測定とは扱わない。

ブラウザー部品検査はViteを自動起動し、ログ・JSON・スクリーンショットを`test-results/rb03-components`へ保存する。依存キャッシュは実行専用で、並行して動くアプリ/検証サーバーのキャッシュを共有しない。終了時は起動したサーバーを停止する。

```sh
RB03_ENGINES=chromium,firefox,webkit node tests/browser/run-rb03-components.mjs
```

任意のChromium実行ファイルは`CHROMIUM_PATH`または`RB03_CHROMIUM_PATH`で指定できる。ポート競合時は`RB03_PORT`、成果物先は`RB03_OUTPUT_DIR`で変更する。個別スクリプトを実行する場合は`RB03_DEV_URL`と`RB03_ENGINE`を指定する。

- `rb03-component-regressions.mjs`: 不正月/途中数値の表示切替、保存待ち入力/閉じる操作の保護、拒否後の再保存、端末幅切替の中心/時点/既定値/配置、保存表示から共有時点への反映、固定世界の読み取り専用イベントとローカル関係、指定した履歴タブへの移動、借用人物の公開名指定の無効化。
- `rb03-timeline-smoke.mjs`: 250重なりの到達、ラベル固定、固定日時衝突、個別承認した連動移動と取消、同じ関係ID、グループ順序、幅320/390/768/1024。

## 結合APIとレビュー修正

`Timeline`と`Relationships`は固定版のreferenceEntities/referenceRelations/referenceCalendarsを受け取り、ローカルProjectDataだけをonSaveProjectへ渡す。`Timeline`はadoptedReferenceIdsをレーン表示に使う。`WorldPanel`はworldTick/checkpointId/onViewPointChangeを通じて時点を共有し、onShowTimeline/onShowEntityTimelineで同じIDへ移動する。requestedSection（histories/maps）は初回と指定変更時のタブ移動に使い、利用者によるタブ操作を妨げない。世界更新のonOpenは第3引数sourceVersionIdで、差分が属する正確な不変版を指定する。親Appは選択IDの変更と読み取り専用プレビューを管理する。

正規の時間解決は`time.ts`の反復処理を全画面・検証・保存で共用する。`timeEditing.ts`は同じresolveEventTimesを再exportし、別の解決処理を持たない。immutableReferenceVersionは既存maintenance処理からexportして引用のスコープ判定を共用する。

独立レビューで再現された旧版引用の誤ブロック、端末切替の時点/中心/既定値の復帰、保存待ち入力消失、半開区間の死亡境界、相対範囲の確定扱い、日付形式切替の入力消失を修正し、回帰検査を追加した。Appのローカル→固定世界イベント選択と正規世界ピンの原子保存・暦衝突拒否は親担当の結合検査に含む。新たな生命例外schemaは作らず、理由・根拠・期間・経路付きappearance_exception記録を既存の型で保存する。

ソースのSHA-256は[所有ファイルmanifest](owned-files.sha256)に記録する。CIと本番Appの段階結果は親担当の隔離検証記録で確定する。
