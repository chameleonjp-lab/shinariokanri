# RB02 共通編集・参照・検索・索引

PR #3で凍結した20要件の段階実装。ここに記す局所検査は、116受入ケースの最終合格や公開の証拠ではない。年表・関係図・公開側索引との結合は後続段階、実端末・アクセシビリティ手動・最終性能判定はRB10で行う。

## 変更範囲

- schemaに沿った通常フォーム、型別参照候補、固定版と現在版を区別した参照先表示。
- 作品ごとの雛形・追加項目・初期値と型変更の影響差分。表示の非表示設定はデータを保持する端末別設定。
- 本文のUnicodeコードポイント範囲、候補リンクの明示選択・除外、段落移動、確定リンクと逆参照、戻り位置。
- メモの文章・画像・音声保存と、元メモを保持する情報変換。
- 複合検索、固定/動的一覧、カード/表、作者の日本語索引、検索結果の本文位置への移動。
- 一括編集・統合の差分と原子保存、補償操作による取消、保持指定・未参照・変更確認候補。
- 作品と情報の組で未保存入力を区別し、再開位置・最近の対象・お気に入りを端末別に保存。
- 公開投影だけを入力にする検索索引API。作者側の秘匿読み・別名・内部IDを混入させない。

## 独立レビューで追加した回帰確認

現在版IDを明示した範囲が本文変更に追従すること、固定版だけを参照するメモを現在版の変更確認に含めないこと、同じ関係の両端を同時変更した場合に両端の影響候補を生成することを検査する。同じ情報IDが別作品に存在しても、それぞれの未保存入力を混線させない。
