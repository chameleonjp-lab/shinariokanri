REQ-F36 / AT-F36、RB08 / RV24の追補。既存の相談用投影・提案取り込み・作者別案比較を保持し、通常の出力画面から人物・場面と型付き前後状態を渡す。

## 操作と保存

「出力する公開範囲」「出力する作品版」「手動相談用」を選び、相談する人物・場面と公開範囲に含まれる状態を指定する。値は作者が指定した相談情報であり、試読の実測・読者の理解を認定する値ではない。未指定値は未知のまま渡し、整数の入力途中も文字列として保持する。型・許容範囲・公開表記は既存の出力契約で検査する。

入力は作品・アカウント・公開範囲・対象版に分けて共通作者下書きへ保存する。移動・cold再起動・保存失敗でも入力を再開できる。確認は現在revision・対象版revision・公開範囲revisionに結び、更新後は入力を保持して再確認を求める。入力中の整数、対象外のID、型不一致、範囲外は出力へ進めない。出力待ちの間に入力が変わる場合は、新しい入力を保持して再検査する。

共通下書きには、localStorageの先行書き込みとDBの確定を区別する端末内のpending印を追加した。DB失敗後のcold再起動で古いDB値が新しい保持入力を上書きしない。最新DB確定だけが同じ入力のキャッシュを確認し、古い非同期結果は新しい入力を承認しない。キャッシュ更新失敗時は古いキャッシュを除去して確定DBから再開し、除去も失敗した場合は具体的な案内を保持する。端末DB・完全ファイルのschemaは変更しない。従来形式の印がないキャッシュから、既に失われた過去入力が回復したという主張はしない。

相談MDは既存投影を通し、秘密・対象外・未承認名・未知理由を漏らさない。提案は手動で出所・相談対象版を付けて作者別案へ取り込み、比較から明示採用する。AIへの自動送信は追加しない。
