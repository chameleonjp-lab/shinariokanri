# RB07 台詞・翻訳・収録・資料・素材・演出

RV18/19とWP19/20の局所実装。原104要件・116受入の正常/境界条件と歴史的証拠は保持する。各実機の録音/Files・ライセンスの実資料確認・最終受入は別判定。

台詞の通常詳細で、理由付き分割・順序付き統合・独立複製の影響を確認する。新台詞/段落/独立演出は新IDを持ち、旧台詞・旧→新Unicode位置対応・公開版は保持する。分割/統合の元は没状態へ移す。ルビ/リンク途中の切断、空境界、異なる話者/意図、各使用場面で隣接しない統合は拒否する。曖昧位置は確認待ちのまま旧対応を保持し、自動採用しない。独立複製では元場面・翻訳・収録の対応を変更しない。

本文/ルビ/話者/演出の変更と単体復元は、翻訳・収録を同じ原子保存で再確認待ちへ移す。改名/並替は原文hashを維持する。旧hashのまま確認工程だけを変えても承認されない。翻訳/収録の詳細で現在の採用原台詞とhashを表示し、確認した基底revision・原文・対象成果物が不変の場合だけ承認保存する。分割した元の対応は手動で新IDへ選び直し、再確認する。

制作の通常画面は台詞・翻訳・字幕の表記/読み候補と人物の口調を対象期間/経路/固定版で照合する。没規則は除外し、時点/経路/提示位置/版/例外が未知なら未確認として残す。自由文の意味や読者の理解を自動認定せず、作者が候補位置と根拠を開く。候補は対象snapshot・段落/台詞・Unicode位置付き指摘として原子保存できる。

資料の取得日時は通常入力欄でUTCのISO日時を保存する。出所、参照箇所、解釈、再配布を資料IDと添付へ結ぶ。取得現実日時・制作期限・演出ms・世界tickは別型のまま扱う。

資料/素材詳細から内容署名/bytes/hashを検査して追加・新版差替えする。旧素材/旧pinは保持し、選んだ参照先だけ差替え、演出/翻訳/収録/媒体の確認先を同じ保存で更新する。資料への新添付も差分確認hashに含める。入力・素材bytesはv4 authorToolDraftsへ保持し、移動/失敗/再起動から再確認して再開する。確認後更新や二重保存は停止する。後続ファイル選択は保存/表示ack後へ保持し、完了入力clearは同じ書込鎖に置く。

画像/音声/動画は署名と保存bytes/hashを検証してblobで表示し、PDF/UTF-8文章/JSON/その他非実行資料は保存して確認する。HTML/SVG/実行ファイルを埋込実行しない。metadata-onlyはbytes不足と表示する。章/分岐の提示位置に結んだ演出/絵コンテは、作者の任意表示でカメラ/字幕/ms/音声/素材へ進み、素材不足でも本文を読める。ゲーム副作用は実行しない。

担当別の翻訳/収録出力は対象版の制作タスク担当で絞り、公開ID/公開文を使う。担当の成果物と依存素材を含め、担当者IDや作者原文hashを出力しない。対象なし/非公開/原台詞不足は停止する。全出力profile/汎用受取の完成はRB08で扱う。

検査: `src/storage/rb07Production.test.ts` と `tests/e2e/rb07-production.spec.ts`。分割/統合/独立複製、内容hash/復元、原子quota失敗、旧pin/clone/空環境往復、期間/没/未知/文字位置、担当出力、入力cold再開、実動画のnative decodeを分ける。素材fixtureはffmpegで作者生成した0.5秒160×90青色MP4と0.25秒440Hz PCM WAVであり、第三者の資料ではない。PNG単体fixtureの署名bytesはdecode証拠ではない。

v3→v4 DB更新は作者制作下書きtable追加のみ。完成内容と対応・添付bytesは完全保存へ含める。作業途中の端末入力は正本/公開投影へ混ぜない。実OS更新/Files/録音/オフライン長時間/実機アクセシビリティは未実行で保留する。
