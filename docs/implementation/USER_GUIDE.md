# ローカル編集と復元の手順（実装中）

アプリを開いて作品を作成する。人物は名前だけから登録し、出来事・場面・メモ等を追加できる。年表の出来事、章の本文、資料の人物は同じ作品のIDを参照する。世界日時と章の順序を別々に編集する。

変更時は保存表示を確認する。「端末内保存済み」はブラウザーの保存が成功した状態。「送信待ち」は同期の確認が終わっていない状態で、接続先未設定のときに「同期済み」と表示しない。保存できない場合は入力を保持したまま再試行するか、一時ファイルに書き出す。未保存のままブラウザーを強制終了すると、入力を保持できるとは保証しない。

完全保存ファイルは作者メモや秘密を含む作者用のバックアップ。公開相手へそのまま渡さない。「作品・保存」の「完全保存・復元」から「完全保存ファイルを作成」を選び、ブラウザー外の保存先へ保管する。「素材bytesを除いて保存」は素材本体を含まないため、完全バックアップではない。ブラウザーの履歴も保存データも一緒に消えることがあるため、履歴だけを外部バックアップの代わりにしない。

復元はファイルを選択し、形式・hash・参照の検査後に作品名と件数・不足素材・既存作品への影響を確認する。新規復元または複製追加から始める。既存作品の置換は復元点と未送信変更を確認してから確定する。破損・不明な版・容量不足では元の作品を変更せず、原因を確認して再試行する。

試し読みでは条件が真の選択肢を選ぶ。不明の条件は未確認として停止する。「戻る」は状態と乱数位置を一緒に戻す。途中開始・仮値を使った経路は通しプレイの証拠と分ける。伏線の検査は必須情報が提示されたかを確認するもので、読み手が理解したことを自動判定しない。

初回はオンラインでアプリを取得する。キャッシュができた後は取得済み作品を通信なしで編集できる。初回取得、未取得の素材、外部資料までオフラインで取得できるわけではない。完全版の対応端末・ブラウザー・容量・性能は受入検証後に確定する。
# 過去の版・別作品の復元

「作品・保存」→「変更履歴」で、理由・版・操作ID・日時を検索する。50件より古い履歴も頁で選べる。変更前/後と対象を選び、「この情報だけの復元を確認」か「作品全体の復元差分を確認」で影響を読む。現在稿が更新された場合は選択を残して再確認する。公開済み版と過去の履歴は残し、復元を新しい変更として保存する。「移行・読み込み前の復元点」からも全体の差分を確認できる。

別作品へファイルを取り込む場合は「完全保存・復元」から「別作品へ明示ID対応で統合」と対象作品を選ぶ。「全IDへ新しい対応先を用意」で追加用の対応を作り、既存情報へ結ぶ箇所を検索して変更する。同IDに差分があれば、現在かファイルの内容を選んで影響を再確認する。未選択や重複した対応は保存できない。入力と元ファイルは端末へ保持し、画面移動や再起動後に再開して影響を確認し直せる。容量不足や保存競合では元の作品と入力を残す。

「完全保存ファイルを作成」でダウンロードした `.scenario` を、端末のFiles/ダウンロードなどアプリ外の保管先で確認する。空の環境では作品一覧の「保存ファイルを読み込む」から検査・確認して復元する。元のIDを保つ復元と、新しいIDにする複製を区別する。素材を除く保存は素材bytesが別途必要で、完全バックアップではない。端末内の履歴だけでは端末消失に備えられない。

復元された元の送信待ちは「接続を再確認する操作」として保管される。認証や共有権限はファイルから復元しない。サーバーとの基底・権限・競合を確認してから同期する。完全ファイルには作者メモや没案も含まれるため、公開用の出力とは用途を分ける。[互換と未確認環境](RB06_RECOVERY.md)も参照する。


## 台詞と制作・素材を更新する

資料一覧の「情報の種類」から台詞/翻訳/収録/資料/素材を開く。台詞の分割・統合・独立複製は理由と影響を確認して保存する。元台詞を残す旧→新対応から新IDを開き、翻訳/収録の原台詞を選び直して現在原文hashを確認する。取得日時は資料のUTC ISO欄へ入力する。素材の追加・差替えはbytesを選び、参照先と確認した版の差分を保存する。画面移動や保存失敗から入力を再開できるが、作品更新後は再確認する。制作タブで時点/経路を選び口調・用語候補の本文位置と根拠を確認し、必要な候補だけ対象版付き指摘として残す。metadata-only素材は不足のまま扱う。
