# RB05 状態・全入口探索の追加実装

2026-10-08、補修PR #9の `f077c9ec916a8a78acf4d6bd2d6e9cb92db60dc6` を基底とする追加分。原104要件・116受入・24工程・6回帰群を保持する。ここではRB05全体の完成を宣言しない。

相互排他は状態変数の型付き値と相手ID、理由、明示例外を保存する。効果群の最終状態で検査し、合法な入替を許す。不正・未知・期限外の一件で金額と所持品も全拒否する。終了時と周回のresetは同じ文脈で原子実行する。

分岐・章の提示は全候補を効果前の同じ状態で観測する。その観測状態をcheckpoint、trace step、章のoccurrenceへ保存し、固定版のIDへ書き換える。再生時は任意欄の偽造も拒否する。旧記録は追加欄なしで再生でき、旧証拠を変更しない。途中開始・stub由来は通し確認へ昇格しない。

開始点を明示しない探索は全宣言入口を順次探索し、100,000状態・一経路10,000遷移・30秒の上限を超える指定を拒否する。提示条件・回収条件の訪問閾値を探索状態へ反映する。必須情報、代替提示、経路例外を体験上の提示順と効果前状態で照合し、根拠経路と開始状態を残す。未知、取消、未探索、途中開始、stubを全経路安全へ換算しない。

保存経路を固定collectionで回帰集合へ宣言する。開始状態、保存版、経路全体、由来、外部方式が一致する範囲だけを数える。主集計は内部状態のfull_play、途中・stub・importedとactual/mixedは別集計。実受領証跡を未接続のactual/mixedは主checkedへ加算しない。現稿の宣言集合は実行対象の旧固定版と別に捕捉し、旧版の再保存で母数が0/0へ戻ることを防ぐ。

通常画面では二保存経路を再生して合流状態を比較し、参照・更新・reset原因から元情報へ移動できる。sceneの台詞IDを章と分岐で同じように提示する。発言の真実・証言・信念の関連と嘘／誤解／引用の意図・根拠を表示するが、読者の理解は判定しない。

追加項目はstrict schema、ID参照収集とclone、履歴、完全保存へ同時に反映した。公開出力で未対応の規則は明示拒否し、台詞依存を除いて挙動を変える投影も拒否する。互換表は別に保持する。
