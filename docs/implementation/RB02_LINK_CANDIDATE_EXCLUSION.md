# 通常本文からのリンク候補除外

REQ-B10 / REQ-F27、AT-B10 / AT-F27の追補。本文入力の通常画面では、候補を見つけても自動リンクせず、同名の人物・一般語・別名を作者が選び分ける既存処理を保持する。

候補の除外ボタンは、任意の親callbackを渡した場合だけ表示されていた。通常の本文欄はそのcallbackを渡さないため、既存の除外保存処理へ到達できなかった。表示条件を選択候補の存在に合わせ、ボタンから既存のaccount / project / source別端末設定と表示状態を更新する。親callbackは従来どおり任意とする。

除外は同じ端末・アカウント・作品・本文の候補表示設定であり、本文や正本へリンクを自動追加/削除しない。既存のリンク、段落ID、Unicodeコードポイント位置、逆参照、固定版を保持する。端末設定を完全ファイルへ移して他端末と同期したという主張はしない。

`tests/e2e/link-candidate-ignore.spec.ts`は二人の同名人物「葵」、一般語「葵」、別名「青い子」、絵文字付き本文とリンク前固定版を持つfixtureを通常画面へ読み込む。未操作時リンクなし、明示選択した人物と別名の2リンク、一般語の候補除外、逆参照、cold後の候補保持を検査する。実完全ファイルの本文/段落ID/2リンク/旧固定版を確認し、空環境newと独立cloneから再起動・完全保存してID対応を照合する。case上限240秒・retry0を維持し、入力/出力の実ファイルと実browser.versionを添付する。
