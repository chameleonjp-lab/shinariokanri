# RB08 制作・媒体・出力・独立ゲーム受渡し

原計画のRB08、RV20〜RV24を通常操作へ接続する候補。未実行を合格へ変えず、旧証跡と元given／when／then／negative_or_edgeを保持する。

## 制作を見積もる

「構成」→「制作」で企画の想定対象／体験／判断、場面の提示とプレイ行動、対応タスクを確認する。工程別の状態・依存・現実期限・詰まりを別々に保持する。対象版を固定した「遊びと物語の差」の確認候補を一操作で保存できる。

固有場面・台詞・素材は再利用元を単位に数える。固定参照は二重計上せず、独立cloneは固有制作、本文上書きは別制作として扱う。回帰経路の対象版と開始由来を表示し、再生できない経路は0件の完了へ換算しない。経路量は訪問回数、制作量は固有数。旧版にある場面が現在稿でアーカイブされても旧経路量を維持する。

見積には単位／速度／根拠／仮定／不明数を記入する。速度がない対象は未知であり0時間ではない。入力は作品別・基底revision付きで画面移動／再起動から再開し、保存失敗後も再試行できる。保存した見積を完全ファイルへ持出す。

## 媒体の改訂を確認する

媒体の詳細で旧公開版、元設定、媒体別本文・範囲・現実予定日・確認先を開く。元設定の変更で媒体本文は置換しない。旧版と現在の元情報の差を確認し、独立した改訂候補を保存する。旧本文と旧pinは保持する。確認後にrevisionが変わった場合は入力を残して再確認する。

## 公開範囲と固定引用

「作品・保存」→「目的別出力」で公開範囲を作り、元作品版と対象を選択する。公開文へのコピーは作者が選択した操作。詳細で情報の状態を確定し、公開名・本文・値・理由・例外を確認する。素材の再配布許可は別に確認する。

固定版の引用は、その版に対して作った確認済み公開範囲を選び「この固定版の公開引用を保存」する。承認後も元snapshotのhashと位置を検査する。失敗した保存を再試行し、再読込して承認を確認する。完全保存／cloneでも元ID対応を維持する。出力の本文リンクは固定版とUnicodeコードポイント位置を含む。試遊では参照先を開き「元の読み位置へ戻る」で復帰する。

出力profileの挙動と明示拒否は[互換表](EXPORT_COMPATIBILITY.md)を参照する。展開したZIPのindex.htmlは通信を要さず、実アプリと同じ実行器を使う。開始点・戻る・周回・演出と素材を確認する。世界tickと演出msと現実期限を混用しない。

## 独立ゲームへ渡し、証跡を戻す

runtime.jsonを出力し、「ゲーム受領と実結果を取り込む」にある独立例を開く。ゲーム側でファイルを選択し、管理主体がgameと宣言された契約に従い勝利／敗北／収集などのゲーム操作を行う。仮入力はstub、ゲーム操作の結果はactual、両方ならmixedとして実行記録から導出する。

測定結果で物語を開始し、経路を進め、受領hash・仕様版・台詞／素材ID・実結果の証跡を保存する。作者アプリで同じ作品版と公開範囲を選択してそのファイルを検査し、内容を確認して受領記録を保存する。元のpackage hash・実行hash chain・機構の結果・再生した最終状態が一致しないものは保存しない。容量失敗／競合後の再確認、cold再読込と完全復元を確認する。

保存境界でも、受領時の公開確認版と対象作品版のhash、世界の期待hash、公開ID対応から実行内容を再構成し、機構・経路・最終状態を再生する。本文を現在稿へ置き換えず、別作品の正本へ借用世界をコピーしない。作品のcloneは作者用IDを変換し、受領済みの公開IDとwire証跡は保持する。保存済みメモ、固定版、履歴、作者別案に含まれる証跡も検査する。

試読から実ゲームの副作用を直接実行しない。この独立例は特定engine全対応やランキング連携ではない。利用者のファイル操作をPC必須にしない。実iPhone／iPadのFiles・オフライン・支援技術は実端末で別確認し、Linux Chromiumの成功で代用しない。

## 相談文を作者別案へ取り込む

確認した相談Markdownを利用者が持ち出す。返された文章の出所、相談対象版、適用を検討する対象を入力して検査する。MDはUTF-8・1 MiB以下。別案として保存し、作者別案の比較画面で必要な変更だけを選択採用する。元の本文は自動更新しない。出所と採用記録を再読込／完全ファイルで確認する。外部AIへの自動送信は追加していない。

## 残る環境

原116受入、実端末Files／録音／IME／支援技術、全性能・Large／2時間、実Auth／RLS／private Storage、最終同一commitのrelease evidenceは後続RB09／RB10で判定する。専用接続先・実試験アカウント・quota／現行費用が未指定で、外部接続が必要な結果は未実行のまま保持する。公開・マージ・課金・外部DB変更は実行しない。
