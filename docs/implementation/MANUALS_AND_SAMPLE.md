# 人間・AI向けマニュアルと全3章サンプル

トップ画面の「人間向けマニュアル」「AI向けマニュアル」から、機能の用途・操作・確認事項を参照できます。作品を開いている間は左メニュー、スマートフォンでは「メニューを開く」から同じマニュアルを開けます。編集中の詳細画面はそのまま保持します。

画面上部の「マニュアル（人間・AI）」は、再認証待ち、接続先からの取得、限定共有・限定編集の画面でも使用できます。

マニュアルには目次、複数語による検索、全文コピー、Markdown保存があります。「テキスト版を開く」は公開サイトの静的ファイルを開きます。AIへ操作を依頼する際は、AI向けマニュアルと、作品から用途・公開範囲を選んで出力した相談用情報を渡してください。

## 星還りの旅人

トップの「全3章のサンプルを開く」で、異世界へ迷い込んだ測量士・澪と冒険者リナの物語を、編集できる新しい作品として端末へ保存します。繰り返し開くと別のIDを持つ作品を作り、既存の作品や編集したサンプルを置き換えません。

まず「資料」のメモから「はじめに」を開き、案内に沿って設定・本文・分岐をたどります。「構成」から3章の本文、状態変化、伏線の手掛かりと回収を確認し、「年表」で出来事と地図・関係のつながりを確認できます。制作・出力・相談の資料も同じ物語へ結び付いています。

人物8人・場所8箇所・3章12場面を中心に、全43種類の情報を結び付けています。主要伏線3件の回収、救助と急行の2経路、作者別案、制作タスク、英訳草稿と収録計画を確認できます。「はじめに：応用操作を試す演習」には、共通世界・反応系列・階層・再利用・変更履歴の試し方も記載しています。

目的別出力では、本文は「読者用・全3章本文」、汎用ランタイムJSONと単体試遊は「試遊用・全3章と外部契約の演習」、制作・翻訳は「制作・翻訳用・全3章」の公開投影を選びます。

サンプルの素材は同梱し、外部サイトから取得する必要はありません。「作品・保存」→「完全保存・復元」から、編集したサンプルを素材本体とともに保管できます。短い分岐だけを試す既存の例は「短い分岐サンプルで試す」から引き続き開けます。

専用接続先での認証・同期・共有、実際の収録や外部ゲームでの動作確認は利用者が実行する操作です。教材データを用意したことを、それらの接続・検証の完了とは扱いません。各操作の手順と前提はマニュアルを参照してください。

## 更新方法

マニュアル本文は [content.ts](../../src/manuals/content.ts) を唯一の編集元とし、アプリ内表示と [format.ts](../../src/manuals/format.ts) の全文出力で共有します。[ビルドスクリプト](../../scripts/build/manuals.mjs) が `public/manuals/human.md` と `ai.md` を生成します。生成物はコミットせず、`npm run build` でアプリとともに作成します。取得済みのアプリではサービスワーカーのキャッシュ対象にも含まれます。

サンプル生成は [adventureSample.ts](../../src/domain/adventureSample.ts) が担います。認証情報や実運用の履歴は含めません。機能を変更した際は、対応するマニュアルと教材の参照・体験手順も更新してください。

この変更は既存の正式受入・公開判定手順を置き換えません。
