## この依頼の検査と終了条件

**検査：** 原ID集合・原文・fixture hashの一致、依存の循環なし、未実施をpassedにできないこと、各候補の現行＋2案／負例／戻し方を確認する。runnerの既存拒否テストと必要な実行入口確認を行う。JSONや検査器を変えたPRは元CIのfull scopeを通す。

**終了条件：** 1A〜1Cが統合され、比較設計と暫定逐条表、実行可能なRUNBOOK、担当path、正確性の境界がある。未確定正式項目と外部待ちが残ったことが明示されている。必要な比較基準がない項目には採用判断を止める条件がある。

- [ ] 誤動作・誤判定の独立期待を先に確定し、変更に必要な反例で失敗を確認してから修正・再確認する。比較だけの案は入力と期待を固定して採否を記録する。
- [ ] 実行コマンド・exit・対象commit / tree / build・fixture・CI run / attempt・原本path / SHAを保存する。原CIと正式受入を別に記録する。
- [ ] 指定単位の成果をレビュー可能なDraft PRへ提出し、必要CIを確認する。ユーザー以外はmerge・公開しない。
- [ ] [引継ぎテンプレート](../HANDOFF_TEMPLATE.md)を使い `handoffs/1D.md` に完了区間・残区間・採否・阻害・次の一操作を残す。PR提出時は統合待ちとする。中断しても別単位へ進めず、この単位の残りから再開できるようにする。
