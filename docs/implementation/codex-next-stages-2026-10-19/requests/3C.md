## この依頼の検査と終了条件

**検査：** 116×4条項・104要件・24工程・6回帰・68補助の集合と原文、独立期待、実結果、証拠bindingを照合する。新しい空領域で取得した実原本と検査器を実行し、元releaseの判定を保存する。証拠／JSON変更は元CIのscopeに従い、製品候補が異なるCI結果を正式証拠に混ぜない。

**終了条件：** 逐条の実判定、最終比較、空領域再取得・全member検査、元release結果、NP16対応、外部22＋別3条件の次操作と最終Draft PRがある。未成立の実条件があれば完成版全合格／公開可能とは宣言しない。

- [ ] 誤動作・誤判定の独立期待を先に確定し、変更に必要な反例で失敗を確認してから修正・再確認する。比較だけの案は入力と期待を固定して採否を記録する。
- [ ] 実行コマンド・exit・対象commit / tree / build・fixture・CI run / attempt・原本path / SHAを保存する。原CIと正式受入を別に記録する。
- [ ] 指定単位の成果をレビュー可能なDraft PRへ提出し、必要CIを確認する。ユーザー以外はmerge・公開しない。
- [ ] [引継ぎテンプレート](../HANDOFF_TEMPLATE.md)を使い `handoffs/3C.md` に完了区間・残区間・採否・阻害・次の一操作を残す。PR提出時は統合待ちとする。中断しても別単位へ進めず、この単位の残りから再開できるようにする。

**次の依頼：** ユーザーのPR確認・merge。その後に必要な外部条件ごとの実行、CP15、X採用は別依頼とする。
