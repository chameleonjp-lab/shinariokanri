## この依頼の検査と終了条件

**検査：** 原checkerとverify_bundleでrawの出所・数値・fixture／bytes・実終了・全量復元を確認し、元CI全inventory／3engine／最終verifyを照合する。旧基準との比較条件が異なるものは比較不能と明記し、改善率を作らない。

**終了条件：** 原正式5実行と必要な同候補の補助結果が完了し、最終比較・実終了・seal・raw／native原本がある。未完了ならその区間は阻害として残し、NP05／06／16をpassedにしない。3Cへ確定可能な証拠と不足を渡す。

- [ ] 誤動作・誤判定の独立期待を先に確定し、変更に必要な反例で失敗を確認してから修正・再確認する。比較だけの案は入力と期待を固定して採否を記録する。
- [ ] 実行コマンド・exit・対象commit / tree / build・fixture・CI run / attempt・原本path / SHAを保存する。原CIと正式受入を別に記録する。
- [ ] 指定単位の成果をレビュー可能なDraft PRへ提出し、必要CIを確認する。ユーザー以外はmerge・公開しない。
- [ ] [引継ぎテンプレート](../HANDOFF_TEMPLATE.md)を使い `handoffs/3B.md` に完了区間・残区間・採否・阻害・次の一操作を残す。PR提出時は統合待ちとする。中断しても別単位へ進めず、この単位の残りから再開できるようにする。

**次の依頼：** 3C。正式試験をもう一度行う依頼ではなく、証拠の独立照合と原条項の確定へ進む。
