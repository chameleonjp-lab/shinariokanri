# RB05 固定共通元の参照・独立複製・部分上書き

原REQ/AT-F19とB14/B15/B16、F13/F14/F15/F17、N19、BEHAVIOR_CONTRACT §7の条件を保持する。固定共通元を使用する通常画面と実行契約の追加であり、RB05全体・104要件・116受入・24工程の完成宣言ではない。伏線の未回収方針／体験上の期限、改訂後の再確認、状態版の引継ぎ、認識比較の全対象条件と原受入全条件は引き続き実装・検証対象である。

場面と分岐ノードの詳細から、共通元の固定版、参照／独立複製／指定項目の上書きを選び、共通元の更新項目と再利用先、使用先でも上書きする変更項目を確認して保存する。確認した作品revisionが進んだ場合は入力を残して再確認する。入力は作品・使用先別の下書きで移動と再読込から再開する。確認を取り消しても入力を保持し、二重保存を防ぐ。保存待ちの再入・失敗は同じ作品・使用先へ通知する。

参照と部分上書きは固定snapshotのhashと依存pinを検証し、実行用ID対応を保存する。借用した依存レコードは実行ビューだけへ展開し、正本／経路snapshotへ複製しない。継承した本文・台詞・状態・条件・開示を章と分岐の同じ提示規則で実行する。現在稿で同じIDの状態宣言が改訂されてID対応が衝突した場合は停止し、旧固定版の対応を確認し直す。現在稿を旧版の代わりには使用しない。使用先の作品／graph／章／経路の対象範囲を変更せず、源の固定版を版条件へ渡す。異なる固定世界版を同時に要求する場合や不採用・不明・破損・欠落・循環は停止する。

継承項目は固定版から表示し、通常入力を無効にする。部分上書きでは宣言したフィールドだけ使用先の入力を使う。独立複製は対象レコード・段落・台詞等のIDを新しくし、内部参照を対応させる。共通元の改稿で参照／複製／上書きを自動置換しない。更新確認は選択した使用先だけに適用し、他の再利用先を影響一覧で確認する。

継承した本文位置は共通元の固定版・元段落／台詞ID・Unicodeコードポイント位置へ戻り、使用先が所有する上書き位置は使用先へ戻る。参照を重ねた場合も元の固定版までID対応を合成する。完全保存・ID対応clone・別projectIdの明示ID対応統合は実行用namespaceを含めて対応し、旧版の再読込・経路再生で照合する。

固定リンク先の表示でも選択snapshotと推移依存pin・固定世界のhashを確認してから同じ実行ビューを解決する。外側の固定版への明示リンクを内側の版へ置換せず、外側に属する条件・提示と内側から継承した本文を表示する。固定本文内の参照は元の版と位置へ移動し、前の固定参照位置へ戻れる。検証中と検証失敗は本文表示を止め、現在稿で代用しない。

参照／部分上書きを公開範囲と合わせて安全に解決する出力はRB08/RV22の実装対象である。現在は公開出力で動作や本文を省略せず、`EXPORT_UNSUPPORTED`として停止する。独立複製は通常レコードの出力規則を用いる。原受入の正常・境界・失敗条件を縮小しない。

検査は `tests/rb05-reuse.test.ts`、`tests/e2e/rb05-reuse.spec.ts` と独立レビューに記録する。部品・IndexedDB保存・productionブラウザー通常操作を区別し、実iPhone/iPad・支援技術・実同期/権限・116原受入全体は未実行のまま保持する。
