# 原契約を保持する試読実装の追加項目

原DATA_MODEL/BEHAVIOR_CONTRACTと計画の凍結hashを変更しない。以下は2026-10-08補修で共通実行へ接続した任意項目の説明であり、元要件・正常・境界/失敗条件の縮小ではない。

RuntimeStateの任意 `resetCauses` は変数ID、scene_end/chapter_end/run_end/new_loop/full_reset、前後の型付き値、理由を保持する。同じ遷移内の各終了原因を残し、巻戻と経路保存・再生へ含む。欠落した部分値はunknownの前値として記録する。原因がなく旧状態に欄がなければ空配列を挿入しない。

Effect/Transitionの任意 `exceptionDetails` は通常の `reason` と別のScenarioException。理由、対象作品/版/章/graph/経路、採用確定した根拠、有限の半開世界期間を評価する。対象外・期限切れ・未知・根拠不足で禁止遷移を許可しない。明示resetは許容遷移の例外とは別に扱い、範囲・型は検査する。

章と分岐は同じ提示処理を使う。全候補条件を同じ提示時状態で観測してから、知識への効果を原子適用する。対象外の開示は現在提示を停止させず、対象内の未知は停止させる。提示ID・段落/台詞・版・コードポイント位置を保持する。世界日時で伏線の提示順を並べない。

Traceの任意 `initialWorldTick` は初期提示時の整数tick。本編開始や出来事日時を変更する欄ではない。章/分岐で開始前に捕捉し、記録保存と再生文脈へ含める。進行時点は各stepの既存worldTickで記録する。期限を評価する時点がない場合はunknownで停止する。

固定世界は選んだsnapshotのhashと推移依存を検証し、借用情報を正本とは別集合で解決する。変数、物品、人物、認識、効果、クエスト、外部契約を同じ採用状態規則へ揃える。再読込・世界改訂・完全保存・複製復元で旧版を現在稿へ代用しない。

型、strict schema、参照収集、clone、履歴と完全保存へ同時に反映する。未知欄を黙って捨てない。明示例外をまだ解釈できない公開runtime/簡易試遊は事前に拒否する。旧正常経路の完全fixtureは書き換えずに再生する。元の116受入と品質gateの完成判定は別に行う。
