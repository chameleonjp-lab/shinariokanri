元AT-F58の入力「未実装かつ人物Aが出る動的一覧と固定ID一覧」をC13 `18bc668` / tree `ec3ed81` / clean build `2503d3e7976b1e7d1643` の通常production画面で確認した。場面追加後の動的1→2／固定1→1、カード・表、原子変更の取消・容量不足の全拒否・再試行・履歴取消・cold・実完全ファイルnew/cloneは確認できたが、同じ結果を図へ切り替えるボタンがなく元whenの正期待が失敗した。元REQの年表も同じ結果集合へ接続されていなかった。[元入力・全source・手順・raw・実ファイル・trace](../quality/current-review/evidence/rb10-candidate/candidate-13-f58-failure/SUMMARY.json)を保持する。

C15は同じ一度評価した検索結果をカード・表・図・年表へ渡す。表示を切り替えても作品・情報・一覧・関係・履歴・送信待ちを書き換えない。動的条件と固定IDの区別、C13の検索再計算抑制、Unicode本文位置を保持する。

図は線のない項目も同じ結果IDのまま表示する。既存の関係評価を使い、意味・向き・出所・根拠・未知を示す。没・別案の関係は有効な線へ含めず、検索された没・仮・要確認の項目は編集対象として状態を明示する。関係は既存の編集フォームと原子保存・版競合拒否へつなぐ。60件の項目ページと線の一覧から、ページをまたぐ線・描画上限を超えた線も確認できる。

年表は同じ全結果IDを登録された世界日時で並べ、日時未定・日時を持たない情報も残す。場面・章・台詞は元の出来事、人物の生涯は元の日時へ戻れる。独立した暦のtickを同じ起点で比較せず、世界日時を章順・提示順・現実期限へ換算しない。没の出来事から現在有効な日時を補わない。60件ページ、選択した情報のページ、詳細を閉じた戻り位置を保持する。

準備確認は部品16件／3ファイル、production Chromium／Firefox／WebKit各1件、独立した元F58入力1件が成功した。図から本文編集、年表から日時元情報編集、原子失敗・入力保持・再試行・一括取消・cold・完全new/cloneを元の期待値で確認する。初回検査のページ件数と既存ARIA名の誤期待、元watchdogによる失敗とrawを保持し、期待を正した再実行と区別する。[準備記録](../quality/current-review/evidence/rb10-candidate/working-collection-views/SUMMARY.json)を参照。
