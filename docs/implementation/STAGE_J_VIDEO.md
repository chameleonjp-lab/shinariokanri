# 工程J 動画台本・場面準備・役の練習

対象案: 21・23・30。動画台本は既存の `dialogue_line` と場面の順序付き `dialogueLineIds` を使う。任意の `scriptKind` は `dialogue / action / subtitle`、省略・nullは従来の台詞として読む。任意の正整数 `scriptNumber` は並べ替えで変更しない行番号、`sourceAnchor` は元の段落または字幕の対応先を示す型付きContentAnchorである。改行後の段落IDと台詞IDを保持し、複製時には通常の参照と同じように付け替える。

現在稿・履歴・snapshot・別案・復旧情報・参照世界のいずれかにこれらの値がある `.scenario` は、manifestの `requiredFeatures` に `video-script-v1` を宣言する。対応しない読込側は書込前に停止する。新しい値のない旧作品に宣言は不要。役の練習位置と答えの開閉は画面内の一時状態であり完全保存には含めない。字幕のみのテキスト出力は作者が場面で確認して作成する端末内の出力であり、読者向けの公開投影には代用しない。

場面の詳細で「動画台本・場面の準備・役の練習」を開く。台詞・ト書き・字幕を切り替え、「動画の行本文」と任意の元の段落・字幕の対応先を指定し、「動画の行を確認」から差分を確認して保存する。話者の未指定は直前の台詞の話者を使う。行の前移動、コマ、無言の人物、環境音の追加と準備状態の変更も差分確認後に一度で保存する。確認後に版が変わった場合は入力を保持して再確認する。

コマと元の行は相互リンクから開く。「場面準備の絞り込み」は仮・未用意・確認済み・要確認を使う。行の変更は明示して結び付いたコマと制作依存先を要確認にする。場面に含まれるという理由だけで兄弟のコマ・演出に影響を広げない。場面全体を対象にした制作タスクは、どの工程でも含まれる全台詞の変更を再確認する。関係のない撮影準備は、その作業が使う人物・音・素材・コマを対象に指定する。

「役の練習に切り替える」または試読の「収録前に役を練習」で役を選ぶ。直前の相手の台詞を見て、自分の答えをタップで開く。前後移動・最初からの操作で答えを閉じる。練習では本文入力欄と全台本表示を閉じ、作品の版・収録済み・制作完了の印を変更しない。

再現: `npm test -- src/storage/stageJVideo.test.ts src/storage/rb07Production.test.ts --maxWorkers=1 --fileParallelism=false` と `npm run test:e2e -- tests/e2e/stage-j-video.spec.ts`。ブラウザ自動化は実機の日本語キーボード、Safari、VoiceOver、文字拡大、実際のファイル操作の確認に代わらない。
